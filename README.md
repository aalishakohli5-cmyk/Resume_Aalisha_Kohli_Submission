# Aalisha Kohli — Portfolio

A personal portfolio website featuring my background, education, projects, and CV.

## Pages

- `index.html` — introduction and links to my work and CV
- `portfolio.html` — education, case competitions, projects, skills, and contact details

## View locally

Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 5500
```

Then visit [http://localhost:5500](http://localhost:5500).

## Main files

- `styles.css`, `home.css` — website styles
- `interactions.js` — page interactions
- `profile-portrait.png` — portrait illustration
- `Aalisha_Kohli_CV.pdf` — CV PDF
